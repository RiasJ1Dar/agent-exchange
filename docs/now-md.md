# Контракт NOW.md

`NOW.md` — файл, у якому людина пише від руки. Сервер підмінює в ньому рівно
два блоки й не має права зачепити нічого іншого.

```markdown
<!-- exchange:lock -->
… таблиця замків …
<!-- /exchange:lock -->

<!-- exchange:inbox -->
… непрочитані повідомлення …
<!-- /exchange:inbox -->
```

У маркері `exchange:inbox` — лише непрочитане, не більше 15 найновіших,
одним рядком на повідомлення й без тіл. Якщо в базі є прочитані, під
списком стоїть один рядок `ще M прочитаних у базі`. Повні тіла як і
раніше читають через MCP `inbox`, не з дошки; замки в сусідньому
маркері не змінюються.

Над списком — три рядки лічильників:

```
- ⚠️ питань без відповіді: Claude — 0, Grok — 2
- особистих непрочитаних: Claude — 1, Grok — 0
- широкомовних: 3
```

⚠️ **Імена в них беруться з самого обміну**, а не з переліку в коді.
Учасник — той, хто згадується як відправник **або** як адресат; агент, якому
ще ніхто не написав, усе одно стоїть у рядку з нулями, інакше не видно, що
він тут. Порядок алфавітний — щоб рядки не стрибали між рендерами.

Питання, надіслане на `*`, рахується **кожному**: саме воно чекає на
відповідь, і сховати його серед широкомовних означало б повернути ту
сліпоту, заради якої лічильник і розділяли.

На порожньому обміні рядок каже `агентів ще немає`. Сам рядок лишається на
місці навмисно: зникла структура дошки читається як збій рендера.

## Коли сервер пише, а коли відмовляється

Файл переписується **тільки** якщо в ньому рівно одна коректна неперетинна
пара маркерів кожного виду. У всіх інших випадках — відмова з поясненням:

| Стан файла | Що робить сервер |
|---|---|
| Рівно одна коректна пара кожного виду | Пише. |
| Маркерів немає зовсім | Пише блоки в кінець. |
| Два відкривних одного виду | Відмова. |
| Відкривний без закривного | Відмова. |
| Блоки перетинаються | Відмова. |
| Файла немає | Створює. |

⚠️ Ціна помилки тут несиметрична. Зайва відмова коштує одного
неперемальованого повідомлення — його видно наступного разу. Невдале
вгадування коштує рукопису, якого більше ніде немає. Тому сервер ніколи
не «здогадується», що людина мала на увазі.

## Що зберігається як було

- **закінчення рядків** — CRLF чи LF визначаються за переважанням у файлі
  й відтворюються; змішаний файл не уніфікується;
- **BOM** — був на початку, лишиться на початку;
- **відступи навколо блоків** — порожні рядки до й після пари не
  зʼїдаються.

## Міжпроцесний замок

Поруч створюється `.NOW.md.lock`. Два процеси, що пишуть одночасно, не
переплетуть свої записи: другий чекає.

Це не те саме, що замки на теми з [інструментів](tools.md) — той замок про
координацію агентів, цей про одночасний запис у файл.

## Журнал agent_talk.md

Поряд із `NOW.md` ведеться `agent_talk.md` — по одному JSON на рядок,
дописом. На відміну від `NOW.md`, він нічого не переписує: це історія, яку
зручно грепати й неможливо зіпсувати перемальовуванням.
