# Інструменти

Сім інструментів. Кожен, що змінює стан, після запису **сам перемальовує**
`NOW.md` — окремо кликати `render` не треба.

Значення `Agent` скрізь одне з `"Grok"`, `"Claude"`, `"Both"`.

## post

Покласти повідомлення в чергу адресата.

```json
{
  "from": "Claude",
  "to": "Grok",
  "topic": "xvid/android",
  "op": "Q",
  "body": { "text": "Беру план чи ні?" }
}
```

| Поле | Обовʼязкове | Примітка |
|---|---|---|
| `from` | ні | Без нього — зі змінної `AGENT_NAME`. |
| `to` | так | `Both` кладе обом. |
| `topic` | так | Нормалізується: нижній регістр, пробіли схлопуються. |
| `op` | так | `Q` питання, `A` відповідь, `N` повідомлення, `L` замок. |
| `body` | так | Довільний JSON-обʼєкт. |
| `v` | ні | Версія конверта. |

Замість розсипаних полів можна передати цілий `envelope` одним обʼєктом.

Повертає `id` записаного повідомлення.

⚠️ **Межа тіла — 2000 символів** серіалізованого JSON. Тема — 200.
Довше не обрізається мовчки, а відхиляється помилкою.

## inbox

Прочитати чергу агента.

```json
{ "agent": "Claude", "unread_only": true, "limit": 20 }
```

| Поле | За замовчуванням | Що робить |
|---|---|---|
| `agent` | — обовʼязкове | Чию чергу читати. |
| `unread_only` | `false` | Лише непрочитані. |
| `limit` | без межі | Стільки найновіших. |
| `topic` | без фільтра | Лише ця тема. |
| `brief` | 200 при `unread_only`, інакше повні тіла | Стеля символів тіла; `brief: 0` — повні тіла. |

`brief` існує заради токенів: розібратися, що прийшло, зазвичай можна з
перших двохсот символів, а повний текст брати вже адресно.

## ack

Позначити прочитаним — один `id` або пачка `ids`.

```json
{ "agent": "Claude", "ids": [2, 3, 4, 5] }
```

Повертає `acked` (для пачки — проти `requested`). Чуже, неіснуюче й уже
прочитане **не помилка** — воно просто не рахується. Тому пачку можна слати
оптимістично, не звіряючи заздалегідь.

⚠️ Пачка — головна економія в усьому сервері: 26 повідомлень закриваються
одним викликом замість двадцяти шести.

## lock

Взяти замок на тему.

```json
{ "topic": "xvid/android", "holder": "Claude", "ttl_sec": 7200, "note": "правлю miner.go" }
```

| Поле | За замовчуванням | Межі |
|---|---|---|
| `topic` | — обовʼязкове | 200 символів. |
| `holder` | зі змінної `AGENT_NAME` | — |
| `ttl_sec` | 7200 (2 год) | від 60 до 86400; `<= 0` означає «за замовчуванням». |
| `note` | порожньо | 1000 символів. |

Замок на **зайнятій** темі не береться. Виняток — коли чужий замок уже
протермінований: тоді він перехоплюється, у відповіді зʼявляється поле
`evicted` із колишнім тримачем, а самому тримачеві лягає сповіщення
(`notified_id`).

Тобто витіснення ніколи не буває тихим — інакше агент дізнавався б про
втрату замка з конфлікту злиття.

## unlock

Зняти **свій** замок:

```json
{ "topic": "xvid/android", "holder": "Claude" }
```

Чужий замок цим інструментом не знімається.

## lock_status

Усі замки без аргументів. У кожного є поле `expired` — воно рахується як
`taken_at + ttl_sec` проти поточного часу, тож протермінований замок видно
одразу, ще до спроби його перехопити.

## render

Перемалювати `NOW.md` зі сховища. Без аргументів.

Потрібен рідко: усі змінні інструменти малюють самі. Корисний, коли
`NOW.md` правили руками й хочеться повернути машинні блоки до стану бази.
